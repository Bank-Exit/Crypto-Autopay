Format 1 — URI scheme directe Recommandé

Le navigateur ou l'OS délègue directement à l'app enregistrée comme handler crypto-autopay://. Nécessite que l'app ait été lancée au moins une fois avec cargo tauri dev.

🚀 Ouvrir l'app (URI scheme) → ouvre crypto-autopay:1:…

Format 2 — Lien HTTPS avec redirection Fallback web

Passe par autopay.libre-market.com/add?code=… qui tente d'ouvrir l'app via JS, sinon affiche la page d'installation. Idéal pour les emails et réseaux sociaux.

🔗 Ouvrir via HTTPS → redirige vers autopay.libre-market.com/add?code=…

Comparaison des formats

FormatURLCas d'usage

Code brut crypto-autopay:1:<payload> Import manuel dans l'app, QR scanner
Pour que le deeplink fonctionne :
1. Lancer l'app au moins une fois avec cargo tauri dev (enregistre le scheme crypto-autopay via xdg-mime sur Linux).
2. Cliquer sur le lien ci-dessus — l'OS délègue à l'app qui affiche la fenêtre "Ajouter cet abonnement ?".
3. Le mode Semi-auto (défaut) affiche une confirmation avant chaque paiement automatique.
